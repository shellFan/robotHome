# Phase16.3 视频导入报告

线上视频 API 在 2026-10-30 当前复核返回 0 条。候选清单 `docs/phase16.2/content/video-candidates.csv` 有 10 条，记录了官方来源和候选播放方式，但 10 条状态均为待 oEmbed/实际播放器复核及管理员审核；播放验证记录为 HTTP check unavailable: TypeError。

未向生产导入视频，未下载搬运视频，未伪造播放量。实际插入数：0。

播放器代码复核发现：PC `VideoDetail.vue` 将 `detail.url` 直接交给 HTML `<video>`，小程序详情页将 `video.url`/`playUrl` 直接交给 `<video>`。现有 10 条候选保存的是 YouTube 网页地址，网页地址不是原生 video 可播放媒体流，因此它们**尚未通过播放链路验收**；YouTube iframe 或官方原站跳转也没有在本项目 PC/微信端验证。当前视频内容仍为 0。

正式导入前需逐条确认视频仍存在、官方发布者、标题、播放许可和中国大陆/微信端可用方式，并先决定平台嵌入或官方跳转的前端表现及小程序业务域名配置。完成验证后走管理后台审核，逐条验收 PC 与小程序播放器。候选不能因官方页面存在就标为可播放。
