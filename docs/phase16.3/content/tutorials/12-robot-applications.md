# 常见机器人应用场景：先验证任务闭环

**内容状态：原创草稿，待技术与后台审核；未发布。**

## 1. 制造与装配

机械臂、移动平台和视觉系统可用于上下料、装配、焊接、喷涂或检测。适用性取决于工件一致性、夹具、节拍、质量要求和换型频率。要把物料供给、定位、异常处理和质量追溯一起纳入单元设计。

## 2. 仓储与物流

移动机器人可承担搬运、配送、盘点或箱件处理。现场评估应覆盖人车混行、窄通道、货架变化、电梯和充电点。指标可包括订单完成率、单位任务时间、拥堵等待、人工接管、系统停机和安全事件，而不能只记录行驶速度。

## 3. 服务、清洁与医疗相关场景

配送、清洁和迎宾机器人需要处理公共空间中的人员、障碍和服务流程；医疗或康复机器人还涉及更严格的设备管理、人员培训、隐私与监管要求。场景中的“辅助”或“自动化”不应被写成未经验证的诊疗效果。

## 4. 巡检、农业与危险环境

地面、空中或足式平台可以搭载传感器采集设备状态、作物或环境数据。需要评估通信盲区、天气、粉尘、反光、续航、数据质量和召回方式。危险区域使用前确认设备认证、防护能力和现场许可；普通商用品不能自动视为适合危险环境。

## 5. 评估一个应用

为任务画出“接收任务—定位—执行—验证结果—上报异常—恢复或召回”的闭环。定义质量、节拍、可用率、人工介入、单位成本和安全指标，采集试点基线并在相同条件下比较。失败时要能停机、恢复和追溯，不能依赖现场人员临时猜测。
