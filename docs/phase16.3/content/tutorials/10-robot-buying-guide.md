# 机器人选购指南：把需求变成验收指标

**内容状态：原创草稿，待技术与后台审核；未发布。**

## 1. 从当前流程开始

记录任务由谁完成、每班工作量、异常类型、质量要求、空间限制和停机成本。把“提升效率”“降低人工”改写为可测量目标，例如每小时合格件数、可接受的误差范围、平均人工接管时间或巡检覆盖率。标注哪些步骤必须由人审批，避免把不稳定的环节一次性全自动化。

## 2. 对照能力和现场约束

按任务核对负载、工作范围、速度、重复精度、移动能力、续航、防护等级、传感器、工具接口、软件接口、网络和环境条件。确认参数是额定值、最大值还是典型值，并问清其测量方式、配置、测试工况和责任主体。核查安装空间、电源、地面、照明、无线网络、工装、人员动线及设备维护条件。

## 3. 评估总拥有成本

采购价格之外，还要估算末端工具、夹具、集成、培训、备件、电池、软件许可、网络、维护、停机与安全验证成本。询问保修范围、备件交期、远程支持方式、数据存储与权限、固件升级策略和退场方案。不同供应商的报价应使用相同的任务范围和验收标准比较。

## 4. 用试点做决定

优先选择一个频次高、边界明确、失败后可恢复的任务。事先约定测试样本、运行时长、成功标准、异常清单、人工介入、数据所有权和回滚条件。试点报告同时呈现成功与失败案例；不能只展示精选视频或单次演示。

## 5. 采购核对表

保存需求说明、供应商回答、配置清单、风险评估、测试记录、验收报告、合同服务条款和维护联系人。对涉及人员安全的应用，委托具备能力的专业团队完成集成与安全验证。
