# 协作机器人基础：协作能力必须落实到应用风险评估

**内容状态：原创草稿，待技术与后台审核；未发布。**

## 1. 协作机器人是什么

协作机器人常用于设计为允许人与机器人共享工作空间的应用。协作不是单一硬件标签，也不表示机器人可以在任何速度、工具和工件条件下与人直接接触。末端工具、夹持的物体、运动路径、控制模式和工作站布局都可能改变风险。

## 2. 先设计应用，再选择模式

ISO/TS 15066 对协作工业机器人系统与工作环境给出安全要求，并补充 ISO 10218 中的要求与指导。常见协作应用会涉及安全额定监控停止、手动引导、速度与间距监控、功率与力限制等概念。每种方式都有适用条件，必须由完整风险评估确定，不能把产品页面中的“协作模式”直接当作验收结论。

## 3. 评估接触风险

分析可触及的机器人部位、速度、动能、夹点、锐边、工具和工件。即使机器人本体输出力受限，尖锐工具、重物或夹具也可能造成伤害。根据场景确定隔离距离、限制速度、停止时间、工具防护和人员培训；任何结构或程序变更后，都要检查原有评估是否仍然成立。

## 4. 试点与记录

选择低风险、重复性强且收益可测的任务。记录部署前后节拍、人工操作步骤、故障率、人工接管和安全停止次数。把安全功能测试、复位方式、维护责任和异常报告纳入交付文档。需要开展接触测量或法规符合性判断时，应使用专业测试设备和合格人员。
