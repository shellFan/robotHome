# 机器人开发学习路线：循序搭建可复现能力

**内容状态：原创草稿，待技术与后台审核；未发布。**

## 1. 先补基础

熟悉一种编程语言、Linux 命令行、Git、网络和基本调试流程。数学方面先掌握向量、矩阵、三角函数、坐标变换和概率基础；硬件方面理解电机、编码器、供电、串口、CAN 或以太网等常见接口。目标是能读懂日志、复现问题并安全地停下设备，而不是一次学完所有理论。

## 2. 用 ROS 2 建立软件能力

从节点、话题、服务、动作、参数和 launch 开始，练习写简单发布者/订阅者，记录和回放 rosbag，再学习 TF、URDF、RViz 和 QoS。使用固定发行版并记录系统、依赖和构建步骤。学会检查节点图、话题频率、时间戳、QoS 与日志，逐步形成可复现的开发环境。

## 3. 在仿真和小项目中练习

先用仿真或低风险教育平台完成移动底盘遥控、传感器数据读取、地图导航、机械臂末端位姿控制等小项目。每个项目至少有目标、硬件与软件版本、运行步骤、测试数据和失败记录。再逐步接入 `ros2_control`、MoveIt 或导航框架，理解各模块的输入、输出和限制。

## 4. 走向实体设备

开始实体测试前，阅读设备手册并检查供电、急停、限位和通信。低速、小载荷、封闭区域运行，设置人工监护与明确的停止条件。修改驱动、控制周期或机械结构后重新验证。涉及工业单元或人员协作时，由专业人员做风险评估和集成验证。

## 5. 建议的学习记录

整理代码仓库、接线图、依赖清单、问题复现步骤、性能测试和安全注意事项。说明自己验证过什么、还没有验证什么；可复现的工程记录比未经测量的能力宣传更有参考价值。
