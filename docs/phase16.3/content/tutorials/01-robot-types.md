# 机器人基础分类：先看任务，再看外形

**内容状态：原创草稿，待技术与后台审核；未发布。**

## 1. 分类回答不同问题

机器人没有唯一的分类轴。按工作场景，可以区分工业、专业服务、消费服务和医疗机器人；按运动方式，可以区分固定机械臂、轮式移动机器人、足式机器人和人形机器人；按任务，还可以分成搬运、检测、清洁、配送、康复等。一个设备可以同时属于多个维度，例如仓库中的移动机械臂既是移动机器人，也承担搬运作业。

“人形”“机器狗”描述外形或运动结构，不等于它的应用类别，也不代表它比其他结构更通用。判断产品时应先问它要完成什么任务、在什么环境工作，再核对自由度、负载、速度、续航、传感器和安全措施。

## 2. 常见机器人类型

- **工业机器人**：用于工业自动化的可编程设备，常见为六轴机械臂、SCARA、直角坐标和并联机器人。机器人本体之外，还需要末端工具、夹具、工件定位、控制柜和安全单元。
- **移动机器人**：使用轮式或履带底盘移动，可由人工遥控、沿固定路线运行，或通过定位与导航在环境中移动。AMR、AGV 的定义和能力会随行业用法而不同，应以具体导航方式和工作边界为准。
- **足式与人形机器人**：以腿足适应台阶、门槛或非结构化地面；人形机器人还包含躯干、手臂和手部，控制与平衡难度高。外形相似不意味着能完成相同任务。
- **服务机器人**：面向工业自动化之外的服务任务，可用于配送、清洁、巡检、农业或陪护等；具体类别以任务和使用环境划分。

## 3. 选择分类时的实用步骤

写一句可验收的任务描述，例如“在固定围栏内将 2 千克零件从料箱取出并放入夹具”。然后列出空间、节拍、载荷、定位误差、人员接近方式和故障恢复要求。用这些条件筛选结构和产品，避免只按外观、自由度数量或宣传片判断。

## 4. 快速核对表

记录：任务边界、环境、机器人结构、移动方式、末端工具、传感器、操作者培训、安全风险、验收指标和维护责任。没有这些信息时，产品类别只能作为检索入口，不能作为采购结论。
