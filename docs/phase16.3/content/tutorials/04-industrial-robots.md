# 工业机器人基础：机器人本体只是工作站的一部分

**内容状态：原创草稿，待技术与后台审核；未发布。**

## 1. 常见结构

六轴关节机器人适合多方向接近和复杂轨迹；SCARA 常用于平面内高速装配；直角坐标机器人沿直线轴运动，工作空间容易规划；并联机构可用于特定高速取放任务。结构名称不能直接决定节拍或精度，实际性能还受负载、臂展、安装方式、工具、工件和运动路径影响。

## 2. 工作站组成

一套工作站通常包括机械臂、控制器、末端执行器、夹具、工件供料、传感器、外围设备、通信和安全系统。系统集成要确认机器人基座、工具中心点、工件坐标、程序速度、负载参数和碰撞空间。工具或夹具变更后，必须重新核对质量、重心、偏置与危险区域。

## 3. 从需求到验收

明确目标节拍、工件变型、定位公差、连续运行时间、换线频率和维护窗口。用真实工件做试验，覆盖供料偏差、夹取失败、设备互锁、断电恢复和急停后的重新启动。验收报告应包含测试样本、运行时长、成功率、故障次数、质量结果和停机原因，不能只以厂商的空载最大速度作为承诺。

## 4. 安全集成

风险来自机器人运动、工具、工件、夹具、外围设备以及人员操作的组合。围栏、联锁、扫描器、速度限制和安全停止方式应由具备相应能力的集成方设计与验证。机器人本体符合某项标准，不自动代表整条产线安全；调试、维护、手动示教和自动运行的安全条件也不同。
