# 机器人传感器：测量值需要坐标、时间与误差说明

**内容状态：原创草稿，待技术与后台审核；未发布。**

## 1. 常见传感器

- **编码器**测量电机或关节转动；零位、传动比、回差和安装误差会影响位置估计。
- **IMU**中的加速度计与陀螺仪测量线加速度和角速度；偏置、振动、温度和安装方向会影响数据。
- **相机与深度相机**提供图像或深度测量；环境光、反射、遮挡、距离和视场都会影响识别与测距。
- **激光雷达**给出距离采样或点云；玻璃、黑色表面、雨雾、粉尘与安装位置可能改变观测质量。
- **力/力矩传感器**测量载荷或接触作用，需要校准并确认传感器坐标系与工具坐标系。

## 2. 时间与坐标

融合数据不是把数值简单平均。各传感器应有清楚的坐标系、时间戳、单位和更新频率。传感器与机器人之间的外参误差，会让地图、抓取点或姿态估计偏移；时间同步误差则会让运动中的目标看起来位置不一致。先检查原始数据、时间戳和 TF，再讨论融合算法。

## 3. 逐层调试

先确认供电、通信与驱动状态，再查看数据范围、丢帧率和更新时间。静止时检查 IMU 零偏；用已知几何目标检查相机或雷达外参；移动时核对里程计方向、单位和坐标变换。记录传感器型号、固件、安装位置、标定日期和环境条件，以便复现问题。

## 4. 按任务选型

从需要测量的物理量出发，再比较量程、精度、视场、采样率、延迟、环境适应性、同步接口、驱动支持和生命周期。高分辨率不等于任务结果更准确；采购前应用目标材料、光照和工作距离做现场测试，并定义数据失效时的安全降级行为。
