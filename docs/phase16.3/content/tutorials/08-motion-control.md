# 运动控制基础：从目标值到可验证的动作

**内容状态：原创草稿，待技术与后台审核；未发布。**

## 1. 控制回路

控制器根据目标值与测量值之间的误差计算控制输入。常见执行链可能包含位置、速度和电流/力矩等层级，但具体架构取决于机器人和驱动器。PID 是常见方法之一；比例、积分和微分项影响响应、稳态误差与噪声敏感性。参数过大可能产生振荡或超调，过小则可能响应迟缓。不同系统需要通过模型和试验确定参数。

## 2. 坐标与轨迹

机械臂程序要区分基座、关节、工具和工件坐标系。一个目标位姿只有在坐标系、单位和工具中心点明确时才有意义。路径规划把目标变成连续运动，还要检查速度、加速度、关节范围、碰撞和工艺约束。移动机器人还需要估计自身位姿，并处理地图误差、定位跳变和路径偏离。

## 3. 建议的调试顺序

先在仿真或离线环境确认关节方向、坐标变换、轨迹范围和碰撞模型。实体调试时从空载、低速、小范围开始；核实急停、保护停止和限位，再逐渐增加速度与负载。同步记录目标值、反馈值、误差、控制输出、驱动器温度和故障码，不要只凭运动观感调整参数。

## 4. 安全边界

软件控制策略不能替代独立的安全功能。实体机器人的限速、限力、停止时间和安全回路必须按整机与应用验证。调参前清场并按制造商程序进入安全模式；不得在人员可触及执行器时随意更改运动参数。
