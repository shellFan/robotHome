# 机器人电池与续航：从能量预算到安全维护

**内容状态：原创草稿，待技术与后台审核；未发布。**

## 1. 先区分功率与能量

电池容量常以安时（Ah）表示，但不同电压下的 Ah 不能直接比较。名义能量可粗略估算为“标称电压 × 容量”，单位为 Wh。若任务平均功率约为 P 瓦，理想运行时间可用可用能量除以 P 粗估；实际还受峰值功率、温度、负载、驱动效率、电池老化、备用电量和电池管理策略影响。

## 2. 续航测量要写明工况

记录机器人型号、电池型号、固件、载荷、速度、地面、坡度、环境温度、传感器和网络状态。至少区分待机、典型任务和高负载任务，使用多次重复测试报告中位数或范围，并说明测试结束条件。厂商公布的续航如果没有同一工况，不应直接与现场结果比较。

## 3. 电池与系统设计

电池管理系统（BMS）通常参与电压、电流、温度和保护状态监测，但不能代替正确的电芯、充电器、线束、散热和机械保护设计。确认设备允许的电池型号、充电器、温度范围、存放条件、运输要求和维护周期。更换电池或充电器后，应按制造商说明重新验证系统。

## 4. 安全操作

使用匹配的原装或明确认可的充电器，不要拆解电池包或混用不匹配的电芯。发现鼓胀、异常发热、异味、漏液或外壳损伤时停止使用并按制造商流程处理。充电、存放、运输和报废应遵循当地规定以及设备说明；电池安全不能只依赖软件告警。
