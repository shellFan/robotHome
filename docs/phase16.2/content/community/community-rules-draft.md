# 机器人之家社区规则

**状态：官方账号待确认；待社区后台审核。**

1. 尊重他人，不发布骚扰、歧视、威胁或违法内容。
2. 转载资讯、图片、视频和代码时标注来源，并确认有权分享；优先链接原始页面，不搬运受版权保护的完整内容。
3. 对产品参数和测试结论注明型号、版本、工况与证据；不编造价格、性能、播放量或用户反馈。
4. 不发布未经授权的个人信息、企业机密、账号凭据和安全漏洞利用细节。
5. 商业推广须明确标识；禁止垃圾广告、虚假交易和诱导互动。
6. 管理员可按平台规则审核、限制或下架内容；用户可通过反馈入口提出申诉。

最终规则需由官方账号确认，并经后台审核后发布。本草稿不代表已生效的法律条款。
