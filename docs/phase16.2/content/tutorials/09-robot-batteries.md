# 机器人电池与续航：先看能量，再看工况

**状态：原创草稿，待后台审核。**

## 1. 容量不等于续航

电池能量可用标称电压乘以安时容量粗略估算为瓦时（Wh）。实际续航还受电机峰值功率、负载、速度、地面、温度、附件和电池老化影响。标称值只能用于初步比较，不是现场保证。

## 2. 看 BMS 与保护

电池管理系统通常监测单体电压、电流和温度，并按设计执行均衡或保护。应确认电池包是否为厂商指定型号、能否热插拔、充电器是否匹配、保护状态如何读取，以及更换电池需要多久。

## 3. 续航测试

在计划工况下重复测量：相同载荷、路线、速度、传感器和环境温度，记录起止电量、任务周期、停机和充电时间。把备用电池、充电等待、维护周期和寿命衰减计入运营成本。

## 4. 安全

仅使用设备厂商指定电池和充电器，遵守电芯规定的电压、温度和充电电流范围。鼓包、过热、破损或进水的电池应立即停用并按供应商流程处置。不要拆解电池包或绕过 BMS。
