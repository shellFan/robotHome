# 机器人选购指南：用任务验收，而不是只比参数

**状态：原创草稿，待后台审核。**

## 1. 写清需求

列出待自动化的任务、当前人工流程、工件变化、节拍、班次、环境、可用空间和异常处理方式。把“想要一台机器人”改写成可测的结果，例如每小时处理量、允许误差、人工接管次数和可用率。

## 2. 核对产品资料

从制造商官方资料确认负载、工作范围、速度、重复精度、续航、接口、防护等级、安装条件、软件授权和售后。参数必须对应具体型号、末端工具和版本；选配件、测试工况和保修边界要单独列明。

## 3. 计算全周期成本

除设备价格外，估算夹具、末端执行器、视觉、工装改造、安全围栏、集成、培训、备件、电池、软件订阅和停机成本。不同平台要按相同任务和相同验收标准比较。

## 4. 做现场试点

选代表性工件和最难工况，约定测试次数、成功判定、节拍、异常恢复和安全验收。要求供应方提供可复现数据，并保留失败样本。演示视频用于初筛，不作为性能验收依据。

## 5. 安全与服务

确认风险评估、系统集成责任、培训、维护周期、软件更新、备件交期和故障响应。工业系统应核对部署地区现行安全标准。
