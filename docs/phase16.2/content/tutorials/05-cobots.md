# 协作机器人基础：协作功能不等于天然安全

**状态：原创草稿，待后台审核。**

## 1. 什么是协作应用

协作关注人和机器人在同一工作空间中的交互方式。机械臂带有力矩传感或速度限制，并不意味着任何工具、工件和工艺都可直接与人并肩作业。风险来自整个应用，包括末端工具、夹点、锐边、工件惯性和操作顺序。

## 2. 常见安全方法

系统可能采用安全监控停止、手动引导、速度与间距监控，或功率与力限制等方法。采用哪种方法要依据风险评估、机器人能力和现场布局。保护停机、急停和安全控制回路也必须按系统设计验证。

## 3. 实施步骤

先定义任务和可预见的误用，再识别碰撞、挤压、剪切和工具伤害风险；选择控制措施后，使用实际工件和工具测试接触情形、速度、距离和停止时间。工位变化、工具更换或软件升级后，应重新评估相关风险。

## 4. 标准状态

ISO/TS 15066:2016 补充 ISO 10218-1/-2 的协作工业机器人应用要求；ISO 网站显示其后续修订项目 ISO/AWI 15066-1 正在制定。项目应核对投产地区现行标准和法规，不应把技术说明书当作合规证明。
