# 机器人传感器：每种测量都有适用边界

**状态：原创草稿，待后台审核。**

## 1. 常见传感器

- **编码器**：测量电机或关节转动，需处理零位、传动比和回差。
- **IMU**：加速度计与陀螺仪测量线加速度和角速度；偏置、振动和安装方向会影响结果。
- **相机/深度相机**：提供外观或深度信息，受光照、反射、遮挡和视场影响。
- **激光雷达**：测量距离点云，受表面反射、雨雾、玻璃和安装位置影响。
- **力/力矩传感器**：测量接触负载，需要校准并正确处理工具坐标系。

## 2. 传感器融合

融合不是把数值简单平均。系统需要统一坐标系和时间戳，了解每个传感器的噪声、延迟、量程和失效模式。机器人运动时，传感器外参误差会让地图、抓取点或姿态估计出现偏差。

## 3. 调试清单

先核对供电和通信，再查看原始数据范围、更新频率、时间戳和丢帧；静止时检查 IMU 偏置，使用已知目标检查相机/雷达外参。异常数据要能触发诊断或安全降级，不能静默地继续驱动执行器。

## 4. 选型提示

按测量目标选传感器，而不是只按分辨率或像素数。工作距离、速度、环境光、防护等级、同步方式、驱动支持和标定工具都会影响整机效果。
