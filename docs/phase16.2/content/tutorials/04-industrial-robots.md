# 工业机器人基础：机械臂参数与工作单元

**状态：原创草稿，待后台审核。**

## 1. 工业机器人是什么

IFR 按 ISO 8373 描述的工业机器人，是可自动控制、可重新编程、多用途、至少三个可编程轴的操纵装置，可固定安装或安装在移动平台上，用于工业自动化。机械臂只是完整工业机器人系统的一种常见形式。

## 2. 参数如何读

- **负载**：不仅是工件重量，还包括夹爪、线缆和偏心力矩。
- **工作范围**：要核对工具中心点能否覆盖整个工艺路径。
- **重复定位精度**：表示反复回到同一目标位置的能力，不等同于绝对精度。
- **速度与节拍**：还受加减速、工艺时间、夹具和安全停机影响。
- **环境与防护**：粉尘、温度、清洗要求和安装姿态都可能改变选型。

## 3. 规划集成

把机器人、末端工具、视觉、工装、输送线、控制柜和安全设备一起设计。先在仿真或离线编程中检查可达性和碰撞，再在现场低速验证坐标系、夹具、路径和故障恢复。最终节拍要在真实工件与生产流程下测量。

## 4. 安全

机器人本体与机器人单元的安全责任不同。ISO 10218-1:2025 针对工业机器人本体，ISO 10218-2:2025 针对工业机器人应用和工作单元。集成、围栏、联锁和风险评估需由具备相应能力的人员完成。
