# 人形机器人入门：自由度之外还要看系统能力

**状态：原创草稿，待后台审核。**

## 1. 结构组成

典型人形机器人有躯干、双臂和双腿，部分机型带灵巧手、头部传感器或移动底座。关节数和自由度因机型而异；自由度多不等于任务能力强，还要看关节扭矩、速度、精度、热管理、控制频率和机械可靠性。

## 2. 感知、规划与执行

相机、深度相机、惯性测量单元和关节编码器提供不同类型的状态信息。控制软件把任务拆成可执行动作，再由平衡、步态和操作控制器协调关节。远程操作、预设动作和自主策略的能力边界不同，展示动作不能证明机器人已能在任意工厂稳定工作。

## 3. 评估实际能力

先问任务是否重复、环境是否结构化、物料和工装是否固定。现场验证应记录一次任务成功率、循环时间、人工介入次数、跌倒或停机次数、恢复时间和安全事件。NIST 的人形机器人基准工作强调以定义明确的任务和指标评估能力，而不是只比较宣传参数。

## 4. 安全提示

人形机器人重心高、关节多，跌倒和夹碰风险需要专门评估。试运行应隔离测试区域，限制速度和力矩，并确保急停、断电和人工接管流程可用。具体安全方案应由集成方结合适用标准和现场风险制定。
