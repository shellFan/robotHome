# ROS 2 入门：节点、通信与控制接口

**状态：原创草稿，待后台审核。**

## 1. 核心概念

ROS 2 是机器人软件的通信和工具生态，不是实时操作系统，也不自动提供功能安全。节点负责一个或一组职责；Topic 适合连续数据流，Service 适合短请求/响应，Action 适合可反馈、可取消的长任务。接口由消息、服务和动作定义。

## 2. 从小例子开始

安装一个仍受支持的 ROS 2 发行版，运行官方 talker/listener 示例，再练习 `ros2 node list`、`ros2 topic list`、`ros2 topic echo` 和 `ros2 service list`。多个进程通信时，要理解 QoS 的可靠性、历史深度和持久性设置；QoS 不匹配可能导致节点发现了却收不到数据。

## 3. 机器人控制

URDF 描述连杆和关节，`ros2_control` 将硬件状态接口、命令接口与控制器连接起来。先使用仿真或 mock hardware 验证接口、控制器和关节限位，再接真实设备。实际硬件驱动、控制周期和实时要求要遵循厂商文档。

## 4. 建议学习顺序

先学工作空间和包，再学节点与通信，随后练习 launch、参数、TF 坐标变换、RViz 和 rosbag。最后才连接实体机器人，并设置速度限制、急停和安全隔离。
