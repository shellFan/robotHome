# 机器人基础分类：先看任务，再看外形

**状态：原创草稿，待后台审核。**

## 1. 什么算机器人

机器人不是某种固定外形。实际分类要看它能否在环境中感知、执行动作，并完成有用任务。国际机器人联合会引用 ISO 8373 的词汇，将工业机器人与服务机器人区分；工业机器人主要用于工业自动化，服务机器人则面向工业自动化以外的人或设备服务。

## 2. 三个常用观察维度

- **用途**：制造、物流、检查、医疗、教育、家庭服务等。
- **运动方式**：固定机械臂、轮式移动、履带式、足式、飞行或多形态组合。
- **工作环境**：围栏内的工位、开放仓库、户外复杂地面，或有人共同工作的区域。

人形、四足、机械臂描述的是结构或运动形态，不是完整的用途分类。同一形态可能服务于不同场景；采购时应先写清任务和环境，再选择机构形式。

## 3. 怎样初步选型

把任务拆成输入、动作和结果：要搬多重的物体、移动多远、是否需要抓取、地面是否平整、附近是否有人、设备每天运行多久。然后核对负载、工作范围、速度、定位能力、续航、通信接口和安全措施。演示视频只能说明某次演示表现，不能替代现场验证。

## 4. 安全与验证

机器人本体只是系统的一部分。工具、夹具、地面、网络和操作流程都会影响风险。工业机器人及系统集成应结合适用的安全标准和现场风险评估；不能因机器人外形小或动作慢就默认安全。
