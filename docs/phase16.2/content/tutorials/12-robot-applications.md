# 机器人应用场景：从流程瓶颈判断自动化价值

**状态：原创草稿，待后台审核。**

## 1. 常见领域

- **制造**：焊接、装配、搬运、检测和机床上下料。
- **物流**：仓库搬运、分拣、盘点和末端配送。
- **巡检与应急**：进入高温、狭窄或危险区域采集信息。
- **医疗与服务**：物资配送、辅助操作或面向公众的引导服务。
- **农业与教育**：监测、采摘辅助、教学和研究平台。

应用标签会随统计口径变化。IFR 的工业机器人和服务机器人分类使用标准定义，NIST 的移动机器人项目则覆盖四足、人形、移动操作等形态；这些维度互相补充，不能混为同一分类表。

## 2. 评估可行性

找出任务的重复性、环境变化、物体差异、人与设备的距离、失败后果和异常恢复方式。可预测、结构化的任务通常更容易先自动化；变化大的任务往往需要更强的感知、柔顺控制和人工监督。

## 3. 设定指标

根据业务选择节拍、成功率、人工接管次数、定位误差、覆盖率、停机时间和单位任务成本。试点前定义样本、统计周期和不通过条件，避免只展示最好的一次运行。

## 4. 持续运营

部署后持续监控工况变化、软件版本、传感器校准、耗材和安全事件。机器人改变环境或与人协同工作时，应复查风险和操作规程。
