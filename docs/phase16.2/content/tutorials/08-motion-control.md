# 运动控制基础：从目标值到安全动作

**状态：原创草稿，待后台审核。**

## 1. 控制回路

控制器根据目标值与测量值的误差计算控制输入。常见系统分为位置、速度和电流/力矩等层级，但具体架构取决于驱动器和机器人。PID 是常用工具之一；参数不当会造成振荡、超调或响应过慢。

## 2. 坐标与轨迹

机械臂需要区分基座、关节、工具和工件坐标系。轨迹规划把离散目标变成连续运动，并检查速度、加速度、关节范围和碰撞。移动机器人还要估计自身位姿并处理定位误差与路径偏差。

## 3. 调试顺序

先在仿真中验证坐标、方向和限位；随后空载、低速、小范围运行；确认急停和保护停止有效后，再逐步提高速度和负载。记录目标、反馈、误差和故障码，避免仅凭观察调整参数。

## 4. 安全边界

软件控制策略不能替代独立的安全功能。实体机器人的限速、限力、停止时间和安全回路应由系统集成方案验证；不得在人员可触及执行器时随意更改运动参数。
