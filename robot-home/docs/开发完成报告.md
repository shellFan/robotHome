## 11. 启动方式

```powershell
# 后端
cd robot-home-server
java -jar target/robot-home-server.jar

# PC 开发（http://localhost:5173）
cd robot-home-web && npm run dev

# 管理后台（http://localhost:3001）
cd robot-home-admin && npm run dev

# Docker 全栈（需先 build 前端 dist）
cd robot-home && docker compose up -d --build

# 小程序：微信开发者工具 → robot-home-miniapp
# 修改 utils/config.js 中 baseUrl 为后端地址
```

## 12. 已知问题

1. **短信**：无真实短信通道，生产需对接并关闭 `sms-dev-mode`
2. **微信登录**：仅接收 openid，未做 code2session OAuth
3. **搜索**：当前 MySQL LIKE，未接 Elasticsearch
4. **文件**：默认本地 `./uploads`，生产建议 MinIO + Nginx 反代
5. **JWT secret**：写在 `application.yml`，生产应外置环境变量
